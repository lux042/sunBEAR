# sunBEAR for Windows

The Windows port is a .NET 8 Windows Forms application. Its source, build instructions, validation notes, and MIT license are in this folder.

Version 1.5.0 includes NYT article imports and authenticated readable-page downloads, accurate record progress, a refreshed library, and Ctrl/Shift multi-selection for downloads and exports.

See README.md for setup and build instructions and VALIDATION.md for limitations. The existing macOS project remains in its original folders.
